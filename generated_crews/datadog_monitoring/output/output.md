## 🎯 권장 사항 (Recommendations)

### 즉시 조치 필요 (High Priority)

1. **로그 분석 매개변수 제공**
   ```
   time_range: "24h"                    # 예: 지난 24시간
   datadog_query: "status:error"        # 예: 모든 에러 로그
   limit: "500"                         # 예: 최대 500개 로그
   recipient_email: "your@email.com"    # 결과 수신 이메일
   output_path: "/tmp/analysis.json"    # 결과 저장 경로
   ```

2. **Datadog 쿼리 예시**
   - 특정 서비스 에러: `"service:api-server status:error"`
   - 심각한 로그만: `"@log_level:(ERROR OR FATAL)"`
   - 모든 서비스 문제: `"service:* status:(error OR warn)"`

### 분석 후 예상 권장사항

실제 로그 분석 완료 후 다음과 같은 권장사항이 제공될 예정입니다:
- **즉시 조치**: 서비스 재시작, 긴급 패치 적용
- **단기 조치**: 모니터링 개선, 알림 규칙 조정
- **장기 조치**: 아키텍처 개선, 로그 정책 수정
